## 这是什么

一套给 DeepSeek Harness 用的插件合集——**装上就能用,零构建、源码看得懂**。

## 代表作:语音朗读(dsh-multi-tts)

让 DSH 开口说话:回复自动朗读,服务商和音色自己挑。

- 多服务商支持,音色、语速、情绪可调
- 在设置页里直接配置,带自动朗读开关
- 一条命令装好,升级不丢配置

## 其他

- 插件都在 GitHub 上开源(MIT),国内可从 Gitee 镜像拉
- 想要什么功能,去对应仓库开 issue 说一声
